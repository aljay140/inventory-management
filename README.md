# inventory-management
## Inventory management project using MERN stack - hands-on learning project.

This is a repository for code pertaining to my endeavor of creating an inventory management program. Going into this, I have very limited knowledge about the MERN stack. I've learned a little bit of javascript, but certainly not enough to do this independantly/without Googling everything the entire time.

### "MERN stack?? what?"
I thought the same thing. Turns out it's a popular framework for making web applications. Google tells me it's a good selection of programming languages to create this sort of thing. It covers basically all the bases you need; frontend, backend, and data storage. The accronym stands for: MongoDB, Express, React, Node.

MongoDB is the database part of the thing. This is where the data is stored.
Express is how the app onteracts with the NodeJS server.
React is how it looks.
NodeJS is the server.

As Geeks for Geeks put it:

    "ReactJS creates the user interface and handles user interactions.
    Users send requests through the React frontend.
    ExpressJS receives and processes these requests.
    NodeJS executes the server-side logic and manages application operations.
    MongoDB, a NoSQL database, stores and retrieves application data.
    Processed data is sent back from the backend to React for display to the user." (GeeksforGeeks, 2019)
